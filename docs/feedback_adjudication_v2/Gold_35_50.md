### FI-035

- **Equivalent.** The expected positive career category `AI solution architecture` (`career_category=ai_solution_architecture`) matched the positive `move_into_ai_solution_architecture` at the same scope in both passes. “I want to move into AI solution architecture” is explicit and strong.
- **Contested reference only.** The expected positive `growth_purpose` feature `training and skill development` (`role_feature=skill_development`) is absent in both. “Even though I would need to learn the tooling” states a prospective hurdle. It can qualify the career goal without expressing interest in training itself or an independently verified skill gap.

### FI-036

The reference and both outputs contain zero preferences. Both profile items correctly preserve the self-reported gap in hands-on SAP integration experience for this contract.

### FI-037

- **Material scope mismatch.** The expected strong negative `role_responsibilities` feature `mostly daily Python coding` (`role_feature=coding_heavy`) was paired with `mostly_writing_python_code` (`role_feature=mostly_writing_python_code`) in both passes. The structured feature retains Python and workload dominance, while only the quote retains the daily cadence. Preserve both “daily work” and “mostly” if scope is used independently of the quote. Neither pass inferred inability to code.

### FI-038

Pass 2 quotes only the reaction, which cannot establish the target on its own. Neither pass treats the posting as the user's positive sentiment or proposes a career downgrade.
